03 / AUDIT REPORT

Issues found & improvements

01
Image overflow

375px viewport · Set images to max-width: 100% and height: auto.

02
Navigation overflow

375px viewport · Stack or wrap navigation links with a media query.

03
Cards too narrow

768px viewport · Reflow the favourites into fewer columns at tablet width.

04
Buttons too close

375px viewport · Increase button padding and the gap between controls.

Responsive checklist

Tested conceptually at 1200px, 768px and 375px. The page uses fluid widths, flexible navigation, responsive cards and no horizontal page scrolling.
